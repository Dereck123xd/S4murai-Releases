## 🚀 Características Principales

*   **Interfaz Gráfica (GUI):** Terminal visual interactiva con lluvia Matrix integrada.
*   **Motor en Python (Backend):** Conexión directa vía WebSockets para ejecución de tareas en tiempo real.
*   **Herramientas de Automatización:** Auto-Deleter, Auto-Kick, Mass Ban, Spammer, Nukes, entre otros.
*   **Auto-Updater:** Sistema de actualización automática para recibir mejoras sin descargar manualmente.
*   **Escáner de Tokens Local:** Detección automática de sesiones en la máquina anfitriona.
